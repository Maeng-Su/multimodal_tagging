# multimodal_tagging

한국 여행지 콘텐츠(사진·텍스트)에 해시태그를 자동으로 붙이는 방식 4가지를 같은 기준으로 비교한 팀 프로젝트입니다. 모두의연구소 아이펠 리서치 12기 미니 아이펠톤(2025.04, 4인 팀)에서 진행했습니다. 저는 팀장으로 주제와 평가 방향을 정하고 평가 지표를 구현했습니다. 지표 코드(`metrics/metrics.py`)는 제가 작성했고, 저장소에는 팀원 계정으로 올라가 있습니다.

## 문제

예측 태그가 정답 태그와 글자까지 같아야 맞은 것으로 치면, 뜻이 비슷한 #야옹이와 #고양이도 오답이 됩니다. 그래서 모델을 비교하기 전에 무엇을 맞은 것으로 볼지부터 정했습니다.

## 평가 방법 — `metrics/metrics.py`

1. FastText 한국어 사전학습 임베딩(cc.ko.300)으로 예측 태그와 정답 태그의 코사인 유사도를 구합니다.
2. 헝가리안 알고리즘으로 예측 태그와 정답 태그를 1:1 매칭합니다.
3. 유사도가 0.6 이상인 쌍만 정답으로 인정합니다.
4. 상위 8개 태그 기준 Precision·Recall·F1(@8)로 집계합니다.

정답은 공개 데이터셋 Korean-Tourist-Spot-Dataset의 Hashtag 컬럼을 그대로 썼습니다.

## 결과

팀이 시도한 세 방식은 Recall@8과 F1@8 모두 비교 기준인 Gemma3:4b보다 낮았고, Precision@8은 BLIP만 더 높았습니다.

| 방식 | P@8 | R@8 | F1@8 |
|---|---|---|---|
| Gemma3:4b (비교 기준) | 0.1441 | 0.3546 | 0.1915 |
| BLIP | 0.1581 | 0.1006 | 0.1230 |
| ViT + KeyBERT | 0.0814 | 0.1776 | 0.1112 |
| CLIP-ko | 0.0500 | 0.1493 | 0.0682 |

## 폴더

- `metrics/` — 평가 지표
- `models/` — 방식별 태깅 코드(BLIP, CLIP-ko, Gemma3:4b Ollama 호출). ViT + KeyBERT 노트북은 이 저장소에 없습니다.
- `experiments/` — BLIP 파인튜닝 등 팀 실험 기록
